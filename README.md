# 🤖 Ricardo AI Agent | دستیار هوشمند ریکاردو

**Ricardo AI Agent** یک دستیار هوشمند مبتنی بر ربات تلگرام است که با هدف ساده‌تر کردن مدیریت کارهای روزمره طراحی و پیاده‌سازی شده است. کاربران می‌توانند درخواست‌های خود را به زبان طبیعی و از طریق گفت‌وگو با ربات مطرح کنند و برای انجام کارهایی مانند مدیریت یادآورها، سازمان‌دهی وظایف، ارسال ایمیل و بررسی قیمت بلیت پرواز از آن کمک بگیرند.

این پروژه با استفاده از Python، سرویس هوش مصنوعی Google Gemini و پایگاه داده SQLite توسعه داده شده است. ساختار ماژولار پروژه نیز امکان تفکیک مسئولیت‌ها و توسعه‌ی بخش‌های مختلف را فراهم می‌کند.

## ✨ قابلیت‌ها

### ⏰ مدیریت یادآورها (Reminders)
- ثبت یادآور با استفاده از پیام متنی
- مشاهده‌ی یادآورهای ثبت‌شده
- لغو یادآورها
- تغییر زمان یادآورها
- زمان‌بندی اجرای یادآورها با استفاده از قابلیت Job Queue در `python-telegram-bot`

### 📝 مدیریت فهرست کارها (To-Do List)
- اضافه کردن کار جدید
- مشاهده‌ی فهرست کارها
- حذف کارها
- انتخاب کارهای مربوط به روز جاری
- مدیریت وضعیت انجام کارها

### 📧 ارسال ایمیل
- دریافت درخواست ارسال ایمیل از طریق تلگرام
- استخراج نشانی ایمیل گیرندگان از متن درخواست
- تولید متن و موضوع ایمیل با کمک مدل هوش مصنوعی
- ارسال ایمیل از طریق SMTP

### ✈️ بررسی قیمت بلیت پرواز
- دریافت مبدأ، مقصد و تاریخ سفر از درخواست کاربر
- تبدیل نام شهرها به کدهای فرودگاهی موردنیاز
- دریافت اطلاعات قیمت بلیت از API خارجی Safarmarket
- نمایش بازه‌ی قیمت‌های به‌دست‌آمده

> عملکرد این بخش به در دسترس بودن API خارجی و سازگاری آن با پیاده‌سازی برنامه وابسته است.

### 🧠 پردازش زبان طبیعی
- تحلیل درخواست‌های متنی با استفاده از Google Gemini
- تشخیص دسته‌ی درخواست و نوع عملیات موردنظر
- استخراج اطلاعات موردنیاز برای اجرای عملیات
- هدایت درخواست به ماژول مرتبط

### 🗄️ ذخیره‌سازی و ثبت گزارش
- ذخیره‌ی اطلاعات در SQLite
- نگهداری تاریخچه‌ی گفت‌وگوها
- ذخیره‌ی یادآورها و فهرست کارها
- ثبت گزارش‌ها و خطاهای بخش‌های مختلف برنامه

## 🛠️ فناوری‌ها و ابزارهای استفاده‌شده

| فناوری | کاربرد |
|---|---|
| `Python` | زبان اصلی توسعه |
| `python-telegram-bot` | ارتباط با Telegram Bot API و مدیریت پیام‌ها |
| `Google Gemini API` | تحلیل درخواست‌های متنی و استخراج اطلاعات |
| `SQLite` | ذخیره‌سازی اطلاعات و تاریخچه |
| `sqlite3` | ارتباط با پایگاه داده |
| `SMTP` | ارسال ایمیل |
| `requests` | ارسال درخواست به API خارجی |
| `python-decouple` | خواندن تنظیمات و اطلاعات محرمانه از متغیرهای محیطی |
| `jdatetime` | کار با تاریخ شمسی |
| `logging` | ثبت رویدادها و خطاهای برنامه |

## 🏗️ معماری و ساختار پروژه

پروژه به‌صورت ماژولار طراحی شده است؛ به این معنا که هر فایل مسئولیت مشخصی دارد و فایل اصلی، ارتباط میان بخش‌های مختلف را مدیریت می‌کند.

| فایل | مسئولیت |
|---|---|
| `main.py` | راه‌اندازی ربات، دریافت پیام‌ها، تشخیص نوع درخواست و هدایت آن به ماژول مناسب |
| `ai.py` | ارتباط با Google Gemini و تحلیل درخواست‌های متنی |
| `reminder.py` | ثبت، نمایش، لغو و تغییر زمان یادآورها |
| `todolist.py` | مدیریت فهرست کارها |
| `mail.py` | آماده‌سازی و ارسال ایمیل |
| `ticket.py` | دریافت و پردازش اطلاعات قیمت بلیت پرواز |
| `sql.py` | ایجاد و مدیریت جداول و عملیات پایگاه داده |
| `history.py` | ذخیره و بازیابی تاریخچه‌ی پیام‌ها |
| `logger.py` | پیکربندی سیستم ثبت گزارش |

### 🔄 جریان کلی اجرای درخواست

1. کاربر پیام خود را در تلگرام برای ربات ارسال می‌کند.
2. پیام و اطلاعات موردنیاز آن در بخش تاریخچه مدیریت می‌شود.
3. ماژول هوش مصنوعی درخواست را تحلیل می‌کند و اطلاعات موردنیاز را استخراج می‌کند.
4. `main.py` بر اساس دسته و نوع عملیات تشخیص‌داده‌شده، ماژول مرتبط را فراخوانی می‌کند.
5. عملیات موردنظر، مانند ثبت یادآور، مدیریت کارها یا ارسال ایمیل، اجرا می‌شود.
6. اطلاعات لازم در پایگاه داده ذخیره یا بازیابی می‌شود و نتیجه به کاربر بازگردانده می‌شود.

## 🚀 راه‌اندازی پروژه

### پیش‌نیازها

- نصب Python
- ایجاد یک ربات تلگرام و دریافت Bot Token از [BotFather](https://t.me/BotFather)
- دریافت کلید API از [Google AI Studio](https://aistudio.google.com/)
- دسترسی به تنظیمات SMTP برای ارسال ایمیل
- دسترسی به API مورد استفاده برای دریافت قیمت بلیت پرواز

### ۱. دریافت پروژه

مخزن را Clone کنید:

```bash
git clone <REPOSITORY_URL>
cd <PROJECT_DIRECTORY>
```

مقادیر `<REPOSITORY_URL>` و `<PROJECT_DIRECTORY>` را با اطلاعات مخزن خود جایگزین کنید.

### ۲. ایجاد محیط مجازی

```bash
python -m venv .venv
```

فعال‌سازی محیط مجازی در ویندوز:

```bash
.venv\Scripts\activate
```

### ۳. نصب وابستگی‌ها

بسته‌های اصلی مورد استفاده در پروژه عبارت‌اند از:

```bash
pip install python-telegram-bot google-genai python-decouple requests jdatetime
```

برای اجرای زمان‌بندی یادآورها، نسخه‌ی نصب‌شده‌ی `python-telegram-bot` باید از قابلیت Job Queue پشتیبانی کند. در صورت نیاز، وابستگی مربوط به این قابلیت را نیز نصب کنید:

```bash
pip install "python-telegram-bot[job-queue]"
```

### ۴. تنظیم متغیرهای محیطی

در پوشه‌ی اصلی پروژه، فایلی با نام `.env` ایجاد کنید و تنظیمات موردنیاز را در آن قرار دهید:

```dotenv
TOKEN_BOT_TELEGRAM=your_telegram_bot_token
ROBOT_NAME=Ricardo

GEMINI_API_KEY=your_gemini_api_key
GEMINI_MODEL=your_supported_gemini_model

DATABASE_NAME=ricardo

EMAIL_SENDER=your_email@example.com
EMAIL_PASSWORD=your_email_password_or_app_password
EMAIL_HOST=your_smtp_host
EMAIL_PORT=your_smtp_port

PASS_ADMIN=your_admin_password
```

**نکات مهم:**
- مقادیر بالا نمونه هستند و باید با اطلاعات واقعی و تنظیمات سازگار با کد پروژه جایگزین شوند.
- مقدار `GEMINI_MODEL` باید نام مدلی باشد که برای کلید API شما در دسترس است.
- برای ارسال ایمیل، اطلاعات SMTP باید متناسب با ارائه‌دهنده‌ی ایمیل تنظیم شوند.
- اطلاعات محرمانه را در GitHub منتشر نکنید.
- اگر کد برای مقدار `EMAIL_PORT` به عدد نیاز دارد، آن را به‌صورت عددی در نظر بگیرید یا تبدیل نوع مناسب را در کد انجام دهید.

### ۵. اجرای ربات

پس از نصب وابستگی‌ها و تنظیم متغیرهای محیطی، دستور زیر را اجرا کنید:

```bash
python main.py
```

سپس وارد تلگرام شوید، ربات را باز کنید و با استفاده از دستور `/start` تعامل با آن را آغاز کنید. برای مشاهده‌ی راهنمای ربات نیز می‌توانید از دستور `/help` استفاده کنید.

- تشخیص درخواست‌های مبهم یا چندمنظوره ممکن است به‌درستی انجام نشود.
- پردازش درخواست‌ها به دسترسی و پاسخ‌گویی سرویس Google Gemini وابسته است.

- دریافت قیمت بلیت به عملکرد و تغییرات API خارجی وابسته است.

- مدیریت خطاها، اعتبارسنجی پاسخ‌های هوش مصنوعی و پایداری عملیات خارجی از بخش‌هایی هستند که می‌توانند در نسخه‌های بعدی بهبود پیدا کنند.
